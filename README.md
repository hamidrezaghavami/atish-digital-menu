# 🍔 منوی دیجیتال فست‌فود آتیش (Atish Digital Menu)

یک منوی دیجیتال مدرن، فوق‌العاده سریع، مینیمال و Mobile-First طراحی‌شده برای اسکن بارکد/QR کد روی استیکرها، میزها و جعبه‌های سفارش **فست‌فود آتیش**.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

- ⚡ **فوق‌العاده سریع و سبک (Ultra-Fast & Lightweight):** بارگذاری در کمتر از ۳۰۰ میلی‌ثانیه، ایده‌آل برای اینترنت‌های موبایل و اسکن سریع بارکد.
- 📱 **طراحی Mobile-First و مدرن:** بهینه‌سازی دقیق برای نمایشگرهای گوشی‌های هوشمند با پشتیبانی از RTL و فونت چشم‌نواز **وزیرمتن (Vazirmatn)**.
- 📂 **جداسازی کامل داده‌ها (Data Separation):** تمامی دسته‌بندی‌ها، آیتم‌ها، تصاویر، ترکیبات و قیمت‌ها به‌صورت متمرکز در فایل `data/menu.json` قرار دارند و به‌سادگی بدون دستکاری کد قابل تغییر هستند.
- 🔍 **فیلتر دسته‌بندی و جستجوی آنی (Instant Search & Filter):** دسته‌بندی‌ها (برگرها، پیتزاها، سوخاری و ساندویچ، ساید و پیش‌غذا، نوشیدنی‌ها) با شمارنده و فیلتر هم‌زمان.
- 🔘 **دکمه‌های شناور دسترسی سریع (Floating Action Bubbles - FABs):**
  - 🟢 **تماس مستقیم (`#22C55E`):** اتصال مستقیم به شماره تلفن رستوران (`tel:...`)
  - 🌸 **اسنپ‌فود (`#FF00A6`):** هدایت مشتری به صفحه سفارش آنلاین در اسنپ‌فود
  - 📏 طراحی شده با فاصله‌گذاری مناسب در انتهای صفحه (`pb-36`) برای جلوگیری از همپوشانی با آخرین کارت منو.
- 🖼️ **نمایش جزئیات آیتم در مودال / Bottom Sheet:** نمایش تصویر بزرگ، برچسب‌های ویژه (تند، محبوب، سرآشپز)، کالری و دکمه‌های سفارش سریع.

## 📁 ساختار پروژه (Project Structure)

## 🛠️ راهنمای اجرا و توسعه (Getting Started)

### ۱. اجرای مستقیم در مرورگر
کافیست فایل `index.html` را در مرورگر یا با افزونه‌هایی نظیر Live Server باز کنید.

### ۲. اجرای پروژه با Vite (توسعه محلی)
```bash
# رفتن به پوشه پروژه
cd atish-digital-menu

# اجرای سرور توسعه Vite
npx vite
# یا در صورت نصب پکیج‌ها:
# npm run dev
```

### ۳. ساخت نسخه نهایی جهت انتشار (Production Build)
```bash
npm run build
```
فایل‌های کامپایل‌شده و بهینه‌شده در پوشه `dist/` قرار می‌گیرند و آماده دیپلوی روی GitHub Pages، Vercel، Liara، Netlify یا هر هاست استاتیک دیگری هستند.

## ✏️ راهنمای ویرایش منو و تنظیمات

### تغییر شماره تماس یا لینک اسنپ‌فود:
فایل `src/config.js` یا بخش `"restaurant"` در ابتدای فایل `data/menu.json` را ویرایش کنید:
```javascript
export const CONFIG = {
  restaurantName: "آتیش",
  phoneNumber: "02188889999",
  phoneNumberDisplay: "۰۲۱-۸۸۸۸۹۹۹۹",
  snappfoodUrl: "https://snappfood.ir/restaurant/menu/atish",
  workingHours: "همه روزه ۱۲:۰۰ ظهر الی ۲۴:۰۰ بامداد",
  address: "تهران، خیابان ولیعصر، نرسیده به توانیر، پلاک ۱۴",
  currency: "تومان"
};
```

### افزودن یا تغییر آیتم‌های غذایی:
در فایل `data/menu.json` در آرایه `"items"` می‌توانید آیتم جدید اضافه کنید:
```json
{
  "id": "b6",
  "categoryId": "burgers",
  "title": "اسموکی برگر دست‌ساز",
  "englishTitle": "Smoky Gourmet Burger",
  "ingredients": "۱۸۰ گرم گوشت گوساله، سس باربیکیو دودی، پنیر گودا، نان بریوش",
  "price": 350000,
  "image": "assets/images/atish-burger.jpg",
  "badge": "🔥 ویژه",
  "calories": "690 kcal",
  "isAvailable": true
}
```
قیمت‌ها به‌صورت خودکار با جداکننده ارقام و ارقام فارسی (مثلاً `۳۵۰,۰۰۰ تومان`) فرمت‌بندی می‌شوند.
