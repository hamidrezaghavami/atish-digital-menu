💻 نصب صندوق آتیش روی کامپیوتر

برای اینکه صندوق‌دار همیشه با یک کلیک مثل یک نرم‌افزار ویندوز وارد شود (بدون باز کردن مرورگر):

  1. ویندوز و مک (Chrome / Edge / Brave): روی آیکون نصب (⊕ یا نمایشگر کوچک) در سمت راست نوار آدرس بالای مرورگر کلیک کنید و Install را بزنید.
  2. مک (Safari): از منوی بالای صفحه File → Add to Dock را انتخاب کنید.
  3. همیشه آماده کار: آیکون آتیش روی دسکتاپ/تسک‌بار ذخیره می‌شود و صندوق‌دار با یک کلیک مستقیم وارد صفحه کد تخفیف می‌شود.
